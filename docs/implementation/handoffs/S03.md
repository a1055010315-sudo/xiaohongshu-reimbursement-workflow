## S04 接口

导出：

```js
import {
  DISBURSEMENT_FRESH_SOURCE_AUDIT_V2_KIND,
  auditDisbursementFreshSourcesV2,
} from "./disbursement_fresh_source_v2.mjs";
```

输入必须是已经通过 S01 `validateDisbursementManifestV2` 的对应切片：

```js
await auditDisbursementFreshSourcesV2({
  sourceFiles: normalized.sourceFiles,
  reimbursementSources: normalized.reimbursementSources
    .filter((source) => source.mode === "fresh_evidence"),
  salaryArtifacts: normalized.salaryArtifacts,
  sourceReview: {
    ...normalized.sourceReview,
    reimbursement: normalized.sourceReview.reimbursement
      .filter((review) => review.mode === "fresh_evidence"),
  },
});
```

调用方必须传入“对应 review 切片”：模块会拒绝未声明的额外 reimbursement/salary review。`published_archive` 必须交给 S02，不能传入本模块。

返回值深冻结，主要字段：

- `transactions[]`：`sourceId/profileId/reviewId + id/date/person/reimbursementAmount`，供 S04 rows/ref 闭合。
- `salaryFacts[]`：artifact 标识、month/category/storeReference、grossPayTotal、payments 和诚实的 `semanticBasis`，供 S04 工资行总额/覆盖闭合。
- `reimbursementResults[]` / `salaryResults[]`：逐来源复核、可选佐证结论和 artifact 绑定。
- `fileBindings[]`：实际 fresh-read 后的 fileId/path/SHA/size/kind/usage/安全验证事实。
- `artifactBindings[]`：每个来源或工资件到完整 reviewed fileId 集合的绑定。
- `boundSourcePaths[]` / `boundSourceDigests[]` / `sourceBindingDigest`：供后续发布审计绑定。
